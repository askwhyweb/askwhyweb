## Selected Engineering Work

- [Ingestion Platform](https://github.com/askwhyweb/ingestion-platform) — a local observability pipeline built around Vector, Kafka, OpenSearch and object storage. It shows how I approach ingestion boundaries, validation, retention, diagnostics and operational guidance without presenting a local evaluation as a production service.
- [MedusaJS Commerce Platform Evaluation](https://github.com/askwhyweb/medusajs-demo) — a containerised commerce evaluation with a Medusa backend, Next.js storefront, PostgreSQL, Redis and catalogue seeding. It explores platform integration and cache refresh behaviour in a clearly bounded local environment.
- [Magento 2 Add to Cart by URL](https://github.com/askwhyweb/magento2-add-to-cart-by-url) — a small historical commerce extension that reflects earlier hands-on work extending Magento storefront flows. It is retained as historical code, not presented as a current platform recommendation.

## Engineering Approach

I favour the simplest architecture that meets the need, with explicit ownership, useful observability and controlled delivery. Technical choices should be understandable to the people who operate them and proportionate to business value, risk and the cost of change.
